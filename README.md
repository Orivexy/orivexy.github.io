# ORIVEXY Validator · demo

Demo interactiva de [ORIVEXY Validator](https://apps.odoo.com/apps/modules/18.0/orivexy_validator), el módulo de Odoo que comprueba IBAN y titulares contra el certificado del banco antes de pagar.

**Abrir la demo:** <https://orivexy.github.io/demo/>

Funciona entera en el navegador con documentos de prueba ficticios: no envía nada a ningún sitio.
La genera `tools/make_demo.py` del repositorio de la aplicación.
